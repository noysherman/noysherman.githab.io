
Noy Sherman - Academic Website
Personal academic website for Noy Sherman, MSc student in the Amnon Bar-Shir Lab at the Weizmann Institute of Science.
The site introduces Noy and provides an overview of the lab’s research in molecular imaging and MRI probes.
Publish with GitHub Pages
Create a public repository named `NoySherman.github.io`.
Upload `index.html` and `.nojekyll` to the root of the `main` branch.
Open Settings → Pages.
Under Build and deployment, select Deploy from a branch.
Choose the `main` branch and `/ (root)` folder, then click Save.
Visit https://noysherman.github.io/.
Personalize
The website can be updated with Noy’s undergraduate degree, specific MSc project, public email address, and optional portrait.
